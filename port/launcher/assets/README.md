# Launcher visual references

The presentation uses warm parchment, desaturated stone, moss green, soft light and
serif titles, inspired by the official environments and Trico's plumage. The initial
screen gives the artwork room; settings and the session log have separate pages.
English and Brazilian Portuguese share the same layout.

## Official artwork

`guardian-hero.png` is a presentation crop of Sony's official screenshot, resized
and shaded for text legibility. It is loaded locally, with no network requests or
additional Python dependencies. The original artwork remains © Sony Interactive
Entertainment; it is not covered by the source code's GPL license.

rendering, input mappings, mods and the game launch path use the existing callbacks.
